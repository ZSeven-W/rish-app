Use case: ui-mockup
Asset type: FINAL revised Rish design board, conversation-centric responsive app. Supersedes earlier global Files/Git navigation designs.
Design FOUR high-fidelity UI artboards on one refined presentation board: TOP row TWO large iPad LANDSCAPE canvases (each wide 1194:834 proportion), BOTTOM row TWO full-height compact iPhone canvases, arranged with clear labels and generous separation. Flat screen UI, no device hardware.
Primary product rule: Every conversation MUST have a workspace. The app automatically provides “默认工作空间”. There are NO global Files or Git menu entries. The global sidebar contains only “Rish”, “新建会话”, “最近会话”, conversation titles, and bottom “设置”. Files and Git belong INSIDE the active conversation. Every conversation displays a compact workspace selector with folder icon and the name “默认工作空间”.
Visual language: extremely polished Codex-inspired minimalist developer workbench, Lucide outline icons, near-white neutral backgrounds, charcoal text and primary buttons, hairline gray separators, rounded 12pt controls and 18pt surfaces, restrained actual green/red diff lines. No gradients, fake stats, arbitrary illustrations, or giant scaled-up type. Same text/control size across phone/tablet.
TOP LEFT iPad landscape: persistent 220pt conversations sidebar; active conversation “改进登录体验”; context toolbar containing the workspace selector and “对话”“文件”“Git”. Split remaining area into readable chat column and an adjacent file browser/document preview panel. Conversation and relevant project context visible simultaneously like a PC. Chat has short user instruction, calm assistant prose/code and compact composer at bottom. Workspace contains “src”, “docs”, “README.md”; show a readable selected-file preview with an actual-looking “编辑” action. There is a discreet “展开工作区” icon control.
TOP RIGHT iPad landscape: SAME active conversation, workspace context FOCUSED/EXPANDED. Sidebar stays conversation-only. Context toolbar still shows active conversation + workspace name and files/Git tabs. Workspace area now uses a 280pt changed-files pane and a large diff pane, “main”, compact “获取”“拉取”“推送”, “暂存全部”“提交”, real-looking changed file rows; full wide Markdown diff. This is focused workspace mode within a conversation, not a separate global Git destination.
BOTTOM LEFT iPhone: same new-conversation header and compact workspace selector “默认工作空间”; local tabs “对话”“文件”“Git”. Elegant hero “今天，我们推进什么？”, minimal suggested prompts, bottom composer with V4 Flash and 高. No bottom navigation.
BOTTOM RIGHT iPhone: same conversation header + workspace selector and local tabs, “文件” selected. Single-column folder/file list, comfortable rows and small new-file/new-folder controls. Preserve conversation identity visibly; no sidebar/global file menu visible.
All Chinese labels should be exact and readable; use sparse true labels. Small external captions “iPad · 对话与工作区”“iPad · 展开工作区”“iPhone · 对话”“iPhone · 对话内文件”. Entire design should feel cohesive and practical, with genuine responsive reorganization, not scaled-up phone UI. No watermark.

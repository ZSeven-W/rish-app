<h1 align="center">Rish，你的口袋 Agent。</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <b>繁體中文</b> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish 是以 Rust 與 GPUI 開發的實驗性原生應用，支援行動端基礎文字對話與本機工作空間。原 React Native 應用已移除。

目前仍是開發預覽。完整 Agent 控制器、工具流程與任務 Live Activity 整合尚未完成；GPUI 簽章發行與 TestFlight 流程尚未驗證。

目前的功能範圍與建置步驟，請參閱[英文指南](README.md)、[簡體中文指南](README.zh.md)及[開發文件](docs/development.md)。

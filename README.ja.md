<h1 align="center">Rish、ポケットの中の Agent。</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <b>日本語</b> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish は Rust と GPUI で開発中のネイティブアプリです。モバイルでの基本的なテキスト会話とローカルワークスペースを扱います。従来の React Native アプリは削除されました。

現在は開発プレビューです。完全な Agent コントローラー、ツールの処理フロー、タスクの Live Activity 統合は未完成です。GPUI の署名付き配布と TestFlight の手順は未検証です。

現在の機能範囲とビルド手順は[英語版](README.md)、[中国語版](README.zh.md)、[開発ガイド](docs/development.md)をご覧ください。

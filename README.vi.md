<h1 align="center">Rish, trợ lý trong túi bạn.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <b>Tiếng Việt</b> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish là ứng dụng gốc thử nghiệm viết bằng Rust và GPUI, dành cho trò chuyện văn bản cơ bản và không gian làm việc cục bộ trên thiết bị di động. Ứng dụng React Native cũ đã được gỡ bỏ.

Đây là bản xem trước dành cho phát triển. Bộ điều khiển Agent đầy đủ, quy trình công cụ và tích hợp Live Activity cho tác vụ vẫn chưa hoàn tất. Bản phát hành GPUI có chữ ký và quy trình TestFlight chưa được xác minh.

Xem phạm vi hiện tại và cách biên dịch trong [hướng dẫn tiếng Anh](README.md), [hướng dẫn tiếng Trung](README.zh.md) và [hướng dẫn phát triển](docs/development.md).

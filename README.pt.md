<h1 align="center">Rish, seu agente de bolso.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <b>Português</b> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish é um aplicativo nativo experimental em Rust com GPUI para conversas básicas de texto e espaços de trabalho locais no celular. O aplicativo anterior em React Native foi removido.

Esta é uma prévia de desenvolvimento. O controlador Agent completo, os fluxos de ferramentas e a integração Live Activity das tarefas ainda estão incompletos. A distribuição assinada do GPUI e o processo do TestFlight ainda não foram verificados.

Consulte o [guia em inglês](README.md), o [guia em chinês](README.zh.md) e o [guia de desenvolvimento](docs/development.md) para o escopo atual e as instruções de compilação.

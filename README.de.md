<h1 align="center">Rish, dein Agent für unterwegs.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <b>Deutsch</b> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish ist eine experimentelle native App in Rust mit GPUI für einfache Textgespräche und lokale Arbeitsbereiche auf Mobilgeräten. Die bisherige React-Native-App wurde entfernt.

Dies ist eine Entwicklungsvorschau. Der vollständige Agent-Controller, Werkzeugabläufe und die Live-Activity-Integration für Aufgaben sind noch nicht fertig. Signierte GPUI-Veröffentlichungen und der TestFlight-Ablauf sind noch nicht verifiziert.

Den aktuellen Funktionsumfang und die Build-Anleitung findest du im [englischen Leitfaden](README.md), im [chinesischen Leitfaden](README.zh.md) und im [Entwicklungsleitfaden](docs/development.md).

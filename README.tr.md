<h1 align="center">Rish, cebinizdeki ajan.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <b>Türkçe</b> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish, mobil cihazlarda temel metin sohbetleri ve yerel çalışma alanları için Rust ve GPUI ile geliştirilen deneysel bir yerel uygulamadır. Önceki React Native uygulaması kaldırılmıştır.

Bu bir geliştirme önizlemesidir. Tam Agent denetleyicisi, araç iş akışları ve görevler için Live Activity entegrasyonu henüz tamamlanmamıştır. İmzalı GPUI dağıtımı ve TestFlight süreci henüz doğrulanmamıştır.

Güncel kapsam ve derleme adımları için [İngilizce rehbere](README.md), [Çince rehbere](README.zh.md) ve [geliştirme rehberine](docs/development.md) bakın.

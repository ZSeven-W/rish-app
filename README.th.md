<h1 align="center">Rish เอเจนต์ในกระเป๋าของคุณ</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <b>ไทย</b> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish เป็นแอปเนทีฟรุ่นทดลองที่พัฒนาด้วย Rust และ GPUI สำหรับการสนทนาข้อความพื้นฐานและพื้นที่ทำงานภายในอุปกรณ์มือถือ แอป React Native เดิมถูกนำออกแล้ว

ขณะนี้เป็นรุ่นตัวอย่างสำหรับการพัฒนา ตัวควบคุม Agent แบบเต็ม ขั้นตอนการใช้เครื่องมือ และการเชื่อมต่อ Live Activity สำหรับงานยังไม่เสร็จสมบูรณ์ การเผยแพร่ GPUI แบบลงลายเซ็นและกระบวนการ TestFlight ยังไม่ได้รับการตรวจสอบ

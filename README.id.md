<h1 align="center">Rish, agen di saku Anda.</h1>

Rish adalah aplikasi native eksperimental berbasis Rust dan GPUI untuk percakapan teks dasar dan ruang kerja lokal di perangkat seluler. Aplikasi React Native sebelumnya telah dihapus.

Ini adalah pratinjau pengembangan. Pengontrol Agent lengkap, alur penggunaan alat, dan integrasi Live Activity untuk tugas belum selesai. Distribusi GPUI bertanda tangan dan proses TestFlight belum diverifikasi.

Lihat cakupan saat ini dan petunjuk build di [panduan bahasa Inggris](README.md), [panduan bahasa Mandarin](README.zh.md), dan [panduan pengembangan](docs/development.md).

<h1 align="center">Rish, आपकी जेब में एजेंट।</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <b>हिन्दी</b> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish, Rust और GPUI से बना एक प्रयोगात्मक नेटिव ऐप है। यह मोबाइल पर बुनियादी टेक्स्ट बातचीत और स्थानीय कार्यक्षेत्रों के लिए है। पुराना React Native ऐप हटा दिया गया है।

यह अभी विकास पूर्वावलोकन है। पूरा Agent नियंत्रक, टूल कार्यप्रवाह और कार्यों का Live Activity एकीकरण अभी अधूरा है। GPUI के हस्ताक्षरित वितरण और TestFlight प्रक्रिया का सत्यापन अभी नहीं हुआ है।

वर्तमान सुविधाओं और बिल्ड निर्देशों के लिए [अंग्रेज़ी गाइड](README.md), [चीनी गाइड](README.zh.md) और [विकास गाइड](docs/development.md) देखें।

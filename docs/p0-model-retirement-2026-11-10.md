模型名较长时会把状态一起截掉。现在状态单独显示，辅助功能标签仍包含完整模型名与状态。

走了四段实际界面操作：手动添加并选用模型、强停后恢复、清空模型列表并保存、
再次强停后恢复。四段均通过，两个冷启动的 PID 和进程启动 ID 均变化。

  冷启动后，原会话 ID、模型 ID 和输入栏里的实际草稿一致，消息数仍为 0。

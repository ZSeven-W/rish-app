## 验证与存储

- Android 在断网 Pixel XL API 33 arm64 模拟器重跑。带探针的 APK 通过 **15 项**，普通 APK 通过 **5 项**。真实应用 UID 下，`unshare -m` 被拒绝，`unshare -U` 在该镜像返回不支持，两者退出码均为 1。Codex 0.153.4 的写入对照仍停在 `bubblewrap_unavailable`，退出 101，未执行命令或写入对照文件。两项结果分别说明当前包缺少 helper，以及当前镜像在应用 UID 下存在额外前提。结果限于此镜像。正式任务仍需可验证的沙箱路径、真实账号和模型。
- iOS 自定义服务商回环 **249 项**、内置服务商桥 **223 项**、模拟器 Provider Policy **548 项**、运行时与下载完整性 **145 项**通过。运行时桥通过 iOS 真机和模拟器 SDK 语法检查。使用已有生成工程和已准备的 Rust 静态库完成 Xcode 26.6 Debug 构建，安装到 iOS 26.0 模拟器并核对二进制。此处验收范围是构建和安装，另有独立回环夹具。
- Android JVM **156 项**和源码预检 **25 项**通过。普通包复用原 Gradle 输出路径，覆盖了约 **125.1 MiB** 的探针包，恢复到 **31.2 MiB**。包内没有 Codex 二进制与探针清单。iOS 使用原有 DerivedData，应用目录 **171 MiB**。Android app 构建目录约 **577 MiB**，iOS DerivedData 约 **356 MiB**。
- 未调用外部模型服务。Mika 与 Poki 均未安装，Rish 设备控制和连接器的实现及真机验证仍在 P2。

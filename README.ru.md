<h1 align="center">Rish — ваш карманный агент.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <b>Русский</b> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish — экспериментальное нативное приложение на Rust и GPUI для базовых текстовых диалогов и локальных рабочих пространств на мобильных устройствах. Прежнее приложение React Native удалено.

Это предварительная версия для разработки. Полный контроллер Agent, сценарии работы с инструментами и интеграция задач с Live Activity пока не завершены. Подписанные сборки GPUI и процесс TestFlight ещё не проверены.

Текущие возможности и инструкции по сборке описаны в [английском руководстве](README.md), [китайском руководстве](README.zh.md) и [руководстве разработчика](docs/development.md).

<h1 align="center">Rish, votre agent de poche.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <a href="./README.ko.md">한국어</a> · <b>Français</b> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish est une application native expérimentale écrite en Rust avec GPUI, pour les conversations textuelles de base et les espaces de travail locaux sur mobile. L’ancienne application React Native a été retirée.

Il s’agit d’une version de développement. Le contrôleur Agent complet, les parcours d’exécution des outils et l’intégration Live Activity des tâches restent incomplets. La distribution signée GPUI et le parcours TestFlight ne sont pas encore validés.

Consultez le [guide anglais](README.md), le [guide chinois](README.zh.md) et le [guide de développement](docs/development.md) pour le périmètre actuel et les instructions de compilation.

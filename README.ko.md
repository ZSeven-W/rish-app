<h1 align="center">Rish, 주머니 속 Agent.</h1>

<p align="center"><a href="./README.md">English</a> · <a href="./README.zh.md">简体中文</a> · <a href="./README.zh-TW.md">繁體中文</a> · <a href="./README.ja.md">日本語</a> · <b>한국어</b> · <a href="./README.fr.md">Français</a> · <a href="./README.es.md">Español</a> · <a href="./README.de.md">Deutsch</a> · <a href="./README.pt.md">Português</a> · <a href="./README.ru.md">Русский</a> · <a href="./README.hi.md">हिन्दी</a> · <a href="./README.tr.md">Türkçe</a> · <a href="./README.th.md">ไทย</a> · <a href="./README.vi.md">Tiếng Việt</a> · <a href="./README.id.md">Bahasa Indonesia</a></p>

Rish는 Rust와 GPUI로 개발 중인 실험적 네이티브 앱입니다. 모바일의 기본 텍스트 대화와 로컬 작업 공간을 다룹니다. 기존 React Native 앱은 제거되었습니다.

현재 개발 미리보기 단계입니다. 전체 Agent 컨트롤러, 도구 실행 흐름, 작업 Live Activity 통합은 아직 완성되지 않았습니다. GPUI 서명 배포 및 TestFlight 절차도 검증되지 않았습니다.

현재 기능 범위와 빌드 방법은 [영문 안내](README.md), [중문 안내](README.zh.md), [개발 가이드](docs/development.md)를 참고하세요.
